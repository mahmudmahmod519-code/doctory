## التعليمات الرئيسية للـ AI (اقرأها جيداً قبل البدء)

أنت مصمم Frontend متخصص بخبرة 6+ سنوات في تصميم واجهات التجارة الإلكترونية الفاخرة.

مهمتك: توليد **كل الصفحات** التالية في دفعة واحدة كمجموعة متناسقة تماماً (Design System موحد).

### الثيم الموحد الإلزامي (يجب تطبيقه على كل صفحة بدون استثناء):

**Brand:** عطور أم القرى (Um Al-Qura Perfumes)

**الألوان:**
- Primary: Deep Navy Blue `#0A1F44`
- Secondary / Accent: Soft Gold / Champagne Beige `#D4B896`
- Background: Deep Navy أو Off-White ناعم `#F8F6F2`
- Text: أبيض على الخلفية الداكنة، Navy على الخلفية الفاتحة
- Success: `#2E7D32` | Error: `#C62828` | Warning: `#F9A825`

**الخط:** خط عربي عصري أنيق (مثل Tajawal أو Cairo أو IBM Plex Sans Arabic)

**الاتجاه:** Full RTL في كل شيء

**الشعار:** استخدم اللوجو الرسمي (زهرة اللوتس الخطية + نص "عطور أم القرى" باللون Soft Gold)

**الأسلوب العام:**
- Modern Luxury (فاخر عصري)
- Clean, spacious, elegant
- Soft shadows, rounded corners معتدلة (12-16px)
- High-end product photography feel
- لا مبالغة في الزخارف

### تأثيرات الحركة والانتقالات (إلزامية على كل الصفحات):

- السرعة: 300ms – 450ms
- Easing: ease-out أو cubic-bezier(0.22, 1, 0.36, 1)
- الأزرار: scale(1.03) + ظل ذهبي أقوى عند الـ hover
- بطاقات المنتجات: translateY(-6px) + ظل أعمق عند الـ hover
- الصور: scale(1.05) خفيف جداً داخل الحاوية عند الـ hover
- تحميل الصفحة: fade-in + حركة صاعدة خفيفة (staggered)
- الـ Modals والـ Dropdowns: fade + scale من 0.95
- لا تستخدم أي حركة bounce أو اهتزاز
- الـ Loading: Skeleton shimmer بلون Soft Gold أو Spinner ذهبي أنيق

### التجاوب (Responsive):
- Mobile-first
- Breakpoints واضحة: Mobile (<768px) | Tablet (768-1024px) | Desktop (>1024px)
- كل العناصر تتكيف بشكل أنيق
- على الموبايل: Sidebar يتحول إلى Drawer أو Bottom Sheet

### User Flow (مهم جداً لتجنب أي لخبطة):

**Guest:**
/ → /perfumes → /perfumes/:id → Add to Cart → يظهر "يجب تسجيل الدخول" → /auth/login أو /auth/register

**Customer:**
Login → / → /perfumes → إضافة للسلة → /orders/cart → Checkout → 
- InstaPay → /orders/:id/upload-receipt
- Paymob → /orders/:id/payment (Iframe)
- Cash → نجاح مباشر
→ /orders/profile/orders → /users/profile → تقييمات → Logout

**Admin:**
Login → /admin/dashboard (إن وُجد) أو /perfumes/admin → إدارة المنتجات / التصنيفات / الماركات / الطلبات / المستخدمين

### المكونات المشتركة (يجب أن تكون متطابقة في كل الصفحات):
- Navbar (Sticky + blur عند التمرير)
- Footer
- أزرار Soft Gold الأساسية
- بطاقات المنتجات
- رسائل الخطأ والنجاح
- حالات Loading / Empty / Error

## ملاحظات نهائية مهمة للـ AI

1. **التناسق أولاً**: كل الصفحات يجب أن تبدو وكأنها من نفس العائلة تماماً (نفس الألوان، نفس الأزرار، نفس المسافات، نفس الحركات).
2. **User Flow**: راعِ تدفق المستخدم في التصميم (مثلاً: زر "أضف إلى السلة" في التفاصيل يوجه للتسجيل إذا كان Guest).
3. **Mobile & Desktop**: صمم النسختين معاً أو أظهر كيف يتكيف التصميم.
4. **الحالات**: كل صفحة تحتوي على Loading / Empty / Error / Success حيث ينطبق.
5. **لا تخترع صفحات إضافية**. التزم بالقائمة أعلاه فقط.
6. ابدأ بتوليد الـ Design System (Navbar, Footer, Buttons, Cards, Colors) أولاً ثم طبقها على كل الصفحات.

ابدأ الآن بتوليد المجموعة الكاملة بشكل متناسق واحترافي.
